## 🚀 How to Enable GitHub Pages

1. Push these updated files to your GitHub repository (`MarkFathy/Hr-insight` or your repository name):
   ```bash
   git add .
   git commit -m "Add Privacy Policy and Account Deletion pages for GitHub Pages"
   git push origin main
   ```

2. Open your repository on GitHub in your web browser.
3. Go to **Settings** > **Pages** (under the "Code and automation" section on the left sidebar).
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` (or `master`) and select either `/ (root)` or `/docs`.
   - Click **Save**.

5. Wait 1-2 minutes. GitHub will generate your live website URL, which will look like:
   `https://<your-github-username>.github.io/<repository-name>/`
